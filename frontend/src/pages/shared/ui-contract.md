# 공유 화면 구현 체크리스트

- 모든 실제 메뉴 leaf는 getMenus의 ID/이름/부모/mobile을 그대로 사용한다. UI-27 본문은 관리 기능 모듈에서 제공하며 UI-22는 메뉴 등록 없이 직접 읽기 전용 안내만 표시한다. UI-06은 생성하지 않는다.
- 모든 자리 화면: 제목/화면 ID/경로, 즐겨찾기, 기간 줄, 다음 단계 안내. 본문에 업무 데이터·입력·저장·삭제를 만들지 않는다. NONE 화면에는 기간 입력을 만들지 않는다.
- YEAR: 연도 이동. YEAR_CUM: 연도 이동과 누계월 선택, 1~선택월 누계. MONTH: 연월 이동과 선택, getMonthClose 조회, CLOSED/OPEN 구분과 마감 안내. 기간은 화면별 메모리에 유지하며 저장 payload는 없다.
- 메뉴/월 상태: 로딩, 빈 메뉴, 서버 오류/재시도/문의 번호. 실패 시 기간과 화면 입력을 유지하고 이전 월의 마감 상태를 현재 월로 표시하지 않는다. 권한은 제한하지 않으며 모바일 비노출 메뉴는 PC 안내와 대시보드 이동만 표시한다.
- shell: 기반 ShellLayout의 헤더/메뉴/PC 탭/본문 영역 사용. 기본 UI-16, DB 2단 메뉴, 즐겨찾기 10개와 최근 5개, 검색 Ctrl+K/Esc, 알림 없음, 사용자 설정. 탭 최대 8개/대시보드 고정/최근 사용 기준 닫기 확인. 보존 탭은 mounted 유지. dirty 닫기/이탈과 beforeunload, 계속 작성/나가기.
- 디자인: 기존 tokens.css와 CSS Modules를 재사용한다. ui-style.md는 미검증 차단 기록이므로 임의 스타일을 거기서 추론하지 않고 요청의 측정값 및 ui-design의 검증된 구조만 적용한다.
- OQ-009 최소 안전 정책: 역전 범위는 400 field=to. 누락 월 OPEN은 서비스에서 합성하여 API 소비자 간 판단을 일치시킨다.
